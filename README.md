# Commissioning
All scripts for commissioning should be available here for all in-person, remote shifters and more.

## Vignetting
This folder contains a code to turn an image taken with camera to a vignette map usable for reconstruction and digitisation

## Barreling
This folders contains the code for the barreling estimation from the image of the equally spaced points. The correction is based on [discorpy code](https://discorpy.readthedocs.io/en/latest/)
